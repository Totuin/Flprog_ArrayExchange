# Проверка 0.1.2 (2026-11-17)

- C++11, GCC, `-Wall -Wextra -Werror -pedantic`: PASS.
- AddressSanitizer + UndefinedBehaviorSanitizer: PASS.
- 58 обменов на имитаторе UART (внутренний буфер 1024 байта); дополнительная сборка с буфером 256 байт — 52 обмена; проверка переполнения внутреннего буфера без записи данных, контрольный вектор CRC, проверки данных, реестра и отложенной записи: PASS.
- Новое: создание всех трёх типов адаптеров без функций, запрет обмена до привязки, назначение функций через setters, отключение записи nullptr, сохранение прежнего конструктора: PASS.
- Пример ручной записи (только для демонстрационного скетча, строка заканчивается LF):
  - `PING`
  - `INFO`
  - `DESCRIBE;0`
  - `GET;2;0`
  - `BEGIN;1*7736`
  - `SET;2;0;42*CAE4`
  - `COMMIT*7BB2`
  - `GET;2;0` (ожидается 42).
- Сигнатуры UART сверены с Flprog_Utilites 1.0.1; mock предоставляет те же виртуальные методы.
- Не проверено: компиляция с реальными Arduino Core и RT_HW, фактический UART, задержки, EEPROM на контроллере. Windows-редактор ещё не реализован.
- Ограничения безопасности и отказоустойчивости описаны в README_RU.md. Использовать для стендовой проверки; не считать готовой автоматикой автоклава.
